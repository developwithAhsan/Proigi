02 / Multiplayer rooms

Play together

OpenIGI's room system uses WebRTC. Host a room or join a friend's room code; the game also has a public-room list in its Co-op screen.

One room. Your squad.

Choose a callsign, then host a new room or enter the code shared by your friend. Proigi passes the room option to the OpenIGI browser client; the room connection is handled by OpenIGI's room service.

For public rooms, open the in-game Co-op section after the client starts.

Choose Host or Join first, then press Play Game. The browser connects to OpenIGI's master server through WebRTC; both players need a compatible OpenIGI build.

04 / Important information

Before deployment

Proigi is a portal for the OpenIGI client. It does not host, bundle or distribute the original commercial game files.

Browser support

The published browser build supports the first six Project I.G.I. missions with the original graphics preset. It requires HTTPS and WebGPU.

Desktop game data

The desktop engine requires a copy of Project I.G.I. that you are entitled to use. OpenIGI's source repository does not include the original game assets.

Independent project

OpenIGI is an independent reimplementation. Proigi is not affiliated with Innerloop Studios, Eidos or the game's publishers.
